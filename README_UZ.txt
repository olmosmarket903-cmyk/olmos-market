OLMOS MARKET — ИНТЕРНЕТГА ЖОЙЛАШ УЧУН ЛОЙИҲА

Нима бор:
- Маҳсулотлар каталоги, қидирув, категориялар ва саватча.
- Буюртмани сервер функцияси орқали Telegram ботга юбориш коди.
- Demo админ қисмидаги ўзгаришлар ҳозирча фақат шу браузерда сақланади.

VERCEL ОРҚАЛИ ЖОЙЛАШ:
1. ZIP файлни очинг.
2. index.html, api папкаси ва vercel.json файлларини GitHub'даги янги репозиторийга юкланг.
3. Vercel'да лойиҳани шу GitHub репозиторийдан импорт қилинг.
4. Vercel → Project Settings → Environment Variables бўлимида қуйидагиларни киритинг:
   TELEGRAM_BOT_TOKEN = BotFather берган бот токени
   TELEGRAM_CHAT_ID = буюртмалар келадиган Telegram чат ID
5. Redeploy қилинг.

TELEGRAM CHAT ID ОЛИШ:
1. Telegram'да @Olmos_Market_Bot ботини очинг ва Start тугмасини босиб /start юборинг.
2. Ўз браузерингизда ушбу манзилни очинг:
   https://api.telegram.org/botTOKEN/getUpdates
   TOKEN ўрнига ўз токенингизни қўйинг.
3. Натижадаги message → chat → id рақамини TELEGRAM_CHAT_ID сифатида Vercel'га киритинг.
4. Бот токенини ҳеч кимга юборманг, чатга жойламанг ва HTML/JavaScript кодга ёзманг.
   Фақат хостингнинг Environment Variables қисмида сақланг.

МУҲИМ:
- Telegram буюртма юбориш функцияси фақат сайт серверга жойланиб, икки муҳит созламаси киритилгандан кейин ишлайди.
- Админ панелда маҳсулот/нарх ўзгартириш ҳали умумий каталогга тарқалмайди; фақат админ браузерида сақланади.
- Барча харидорларга бир хил маҳсулот ва нарх кўрсатиш учун алоҳида база ҳамда парол билан ҳимояланган админ панели керак.
- Сайтни аккаунт очиш ва интернетга жойлаш жараёнида ота-она/ишончли катта ёрдамида амал қилинг.
